# Nike Sales Dashboard 👟📊

An interactive **Nike Sales Analysis Dashboard** created using Microsoft
Power BI to analyze sales, revenue, profit, products, regions, customers,
gender, and sales channels.
## 📊 Dashboard Preview

![Nike Sales Dashboard](nike-dashboard.png)
## 🚀 Key Features

- 📈 Sales and revenue analysis
- 💰 Profit analysis
- 🌍 Regional sales analysis
- 👟 Product and brand analysis
- 👨‍👩‍👧 Gender-based analysis
- 🛍️ Sales channel analysis
- 📅 Monthly profit analysis
- 🎟️ Discount analysis
- 👥 Customer analysis

## 🔍 Dashboard Analysis

The dashboard analyzes Nike sales data across:

- **Regions:** Asia, North America, Europe
- **Countries:** India, Japan, China, and others
- **Product Categories:** Accessories, Apparel, Shoes, Performance
- **Brand Lines:** Nike Air, Nike Air Max, Nike Premium
- **Gender:** Female and Male
- **Sales Channels:** Retail Store, Online, Distributor

## 📈 Visualizations

The dashboard includes:

- Total Revenue by Region
- Profit by Month
- Region and Country Analysis
- Product Category Analysis
- Brand Line Analysis
- Revenue and Profit by Gender
- Units Sold by Sales Channel
- Total Profit Trend
